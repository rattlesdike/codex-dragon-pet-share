# Codex GPT 龙娘桌宠

Windows x64 的白紫 GPT 龙娘桌宠，跟随 Codex 窗口右下角，支持角色、动画、音效、气泡编辑、资源管理和用量统计。这是社区改编项目，不是 OpenAI 官方插件或官方角色。

## 下载与安装

从 [最新版本](https://github.com/rattlesdike/codex-dragon-pet-share/releases/latest) 下载 `Codex-Dragon-Pet-Share-20261017.zip`。外层包包含插件 ZIP、演示视频和中文使用教程。

1. 解压外层包，再完整解压其中的 `Codex-Dragon-Pet-Plugin-1.1.0-Windows.zip`。
2. 保持 Codex 打开，双击 `Install-Dragon-Plugin.vbs` 安装或升级。
3. 按包内 `PLUGIN-QUICKSTART.md` 配置自己的账户；以后启动 Codex 自动跟随。

不需要管理员权限或额外安装 Node.js。内置 Electron，安装及 Codex 插件缓存请预留约 1.3 GB 可用空间；不是只有一张角色图片。不会修改 Codex 文件、WindowsApps 权限或阻止客户端更新。旧版本仍保留在 Releases。

## 官方订阅支持什么

- 使用本人 ChatGPT 官方账号登录 Codex 后，读取接口提供的剩余额度百分比、额度窗口、重置时间及额外点数。
- 用量面板可查看和刷新；官方模式的完成气泡可显示额度状态。
- 读取本机 Codex 日志，显示逐轮 Token、模型和用量；设置价格后可显示本地金额估算。
- 通过本机 Codex app-server 查询额度，不读取或导出登录令牌。缺失或失败显示不可用，不显示成零。

**官方额度不是现金余额或逐轮实际扣款。** 点数没有被换算成美元。本插件不提供官方逐轮现金账单。使用 API Key/中转站时不能查询上游会员账号的官方额度。

## 中转站支持什么

- 用户自行登录并授权受支持站点后，读取该站提供的账户余额和账单；当前授权流程适配 PhuketAI。
- 未授权时，可尝试当前 Codex 密钥所支持的同域余额查询。
- 本机请求 ID 与站点账单请求 ID 精确匹配后，可以显示该轮实际扣款。
- 账单尚未入账、缺少请求记录或无法匹配时，显示待入账、部分实扣或未核实，不以余额差推算逐轮消费。

站点支持受其接口、权限和账单延迟影响，不保证任意中转站可用。网站授权账号与当前 API Key 账号可能不同，界面会区分来源。每位使用者须自行登录授权，本包不包含账号或赠送额度。
