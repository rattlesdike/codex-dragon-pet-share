# Codex GPT 龙娘桌宠分享包

这是一个面向 Codex 桌面端的 GPT 龙娘桌宠分享包，包含桌宠插件、配套资源和使用教程。它不是 OpenAI 官方发布的插件。

## 功能与账户模式

### 官方 Codex 订阅

- GPT 龙娘桌宠、跟随 Codex 窗口、气泡提示、动画和音效
- 本机读取 Codex 日志，显示模型、Token 和逐轮用量统计
- 可根据本地配置的价格计算估算金额
- 估算金额仅用于本地参考，不代表 OpenAI 官方逐轮账单或实际扣款

官方订阅不会向本插件提供官方会员额度、账单明细或隐藏的账户数据。插件也不会共享或导出官方登录信息。

### 中转站

- 用户自行登录并授权中转站账户后，可读取该站提供的余额和账单信息
- 如果本机请求 ID 能与中转站账单中的请求 ID 成功匹配，气泡可以显示该轮实际扣款
- 账单尚未入账、请求 ID 无法匹配或接口不支持时，会显示待入账/未核实，不会用余额差额猜测单轮消费

中转站功能取决于站点接口权限、账单延迟和站点实现。请不要把 API Key、授权令牌或密码提交到公开仓库。
